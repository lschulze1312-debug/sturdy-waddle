# FPS Optimization Toolkit

## Installation

```bash
pip install -r requirements.txt
```

## Als Python-Programm starten

```bash
python fps_toolkit.py
```

## Als .exe Anwendung bauen

```bash
python build.py
```

Die fertige `.exe` liegt danach im `dist/` Ordner.

## Funktionen

- FPS-Optimierung für Gaming
- System-Monitoring (CPU/GPU/RAM/Temperaturen)
- Hintergrund-Prozesse beenden
- Windows-Dienste optimieren
- Echte Windows-Registry-Optimierungen
- Wiederherstellungsfunktion

## Ordnerstruktur

```
fps_toolkit/
    core/           - Kernfunktionen
    gui/            - Benutzeroberfläche
    utils/          - Hilfsfunktionen
```
